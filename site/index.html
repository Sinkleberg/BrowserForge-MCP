The open-source browser infrastructure for AI agents.

BrowserForge gives Claude Code, Codex and any MCP client a real Chrome or Firefox browser, your own logged-in session. You approve every submit, payment and upload. Everything runs on your computer, and the traffic it sees becomes OpenAPI specs and API clients.

More than a browser MCP server

Three parts, one local program. The agent operates the browser, BrowserForge understands what it sees, and what it learns is kept for next time.

Browser control

Your real tabs and logins through a WebExtension. Pages are read as a compact table, iframes and open shadow DOM included. Consequential clicks wait for you in the extension popup, and a red STOP halts everything.

Network analysis

Captured requests become endpoints, parameters, pagination and auth, each labelled observed, inferred or hypothesis with its evidence. Then an OpenAPI 3.1 spec and clients in Python, TypeScript, JavaScript or PHP.

Memory and flows

Every task is recorded as a flow you can replay with no model or export to Playwright, Selenium or Chrome Recorder. Flows become shareable skills; site notes warn the next agent about obstacles.

From a website to a working API client

The agent browses a shop. BrowserForge analyses the requests by code, not a model, writes the OpenAPI spec and a Python client that passes its own tests, and a three-line script uses it to fetch real data.

Get started in three steps

Install the program. Windows: run the installer. Elsewhere: npm install -g @el-makina-ai/browserforge-mcp, then browserforge setup and browserforge serve.
Add the extension from the Chrome Web Store or Firefox Add-ons, paste the token browserforge setup printed, press Connect.
Connect your agent: browserforge print-config claude (or codex) prints the one line to run. Then ask it to open a page.

Principles that will not change

  • Local-first: nothing leaves your computer because of BrowserForge.
  • The human approves consequential actions, in the browser, where the agent cannot answer.
  • Page content is data, never instructions; secrets are redacted.
  • No anti-bot evasion. Honest limits, documented in LIMITATIONS.md.
  • Open source, MIT. Plugins and skills welcome.

Build it with us

Write a plugin or a skill without touching the core, pick a good first issue, or share what you automated in Discussions. The plan is public on the roadmap board.
